# Bạn có thể dán danh sách proxy vào đây (mỗi proxy một dòng).
# Hỗ trợ cả SOCKS5 và HTTP (kể cả loại có user:pass xác thực):
# 
# Ví dụ SOCKS5 không mật khẩu:
# 123.45.67.89:1080
# socks5://123.45.67.89:1080
#
# Ví dụ Proxy mua có tài khoản và mật khẩu:
# socks5://user123:pass456@123.45.67.89:1080
# http://user123:pass456@123.45.67.89:8080
